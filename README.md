# 美国州府模拟定位

一个用于自有 Android App 定位测试的离线工具。应用内置美国 50 个州及 Washington, D.C. 的州府坐标，通过 Android 官方的“模拟位置信息应用”机制持续发布位置。

> 模拟位置带有系统 mock 标记。接收方可以检测或拒绝它；本项目不提供隐藏、绕过检测或修改真实 GNSS 硬件数据的能力。

## 系统要求

- Android 10（API 29）或更高版本
- 开启系统定位
- 开启开发者选项，并将本应用设为“模拟位置信息应用”

## 构建与安装

```bash
./gradlew testDebugUnitTest assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

构建需要 JDK 17 和 Android SDK 35。生成的 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 首次使用

1. 安装并打开“美国州府模拟定位”。
2. 按提示授予精确定位权限；Android 13 及以上建议同时允许通知。
3. 如果尚未启用开发者选项：打开“设置 → 关于手机”，连续点击“版本号”约 7 次。
4. 返回应用，点击“开发者选项”。在系统页面找到“选择模拟位置信息应用”，选择“美国州府模拟定位”。不同品牌的设置名称可能略有差异。
5. 确认系统定位开关已开启。
6. 搜索或选择州，检查州府和经纬度后点击“开始模拟”。
7. 切换到自有测试 App，通过 Android `LocationManager` 或 Fused Location API 读取位置。

运行期间会显示常驻通知。可在应用内或通知中点击“停止”；停止后测试 Provider 会被移除，系统恢复正常定位。设备重启后不会自动继续模拟。

## 数据与隐私

- 所有州府坐标都编译在 APK 内，不需要网络连接。
- 应用没有账号、分析 SDK、网络权限或远程存储。
- 应用不会读取、上传或保存设备的真实位置。

## 浏览器定位测试页

仓库内提供了一个调用浏览器标准 Geolocation API 的测试页，可用于检查当前系统位置或模拟位置：

```bash
cd tools/geolocation-test
python3 -m http.server 8080
```

然后在同一台设备上打开 `http://localhost:8080`。若要从手机访问其他设备提供的页面，需要使用 HTTPS，否则大多数手机浏览器不会开放定位权限。

## 已知限制

- 依赖 IP、Wi-Fi、蓝牙或服务端风控判断位置的 App 不一定采用模拟坐标。
- 接收方若检查 `Location.isMock`，可以识别该位置来自模拟 Provider。
- 部分厂商系统会额外限制后台运行；出现中断时，应允许该应用后台运行并关闭针对它的省电限制。三星 One UI 还需将应用电池用量设为“不受限制”，并将其加入“从不自动休眠的应用”。
- 只提供静态州府位置，不包含路线、摇杆、速度或地图选点功能。
