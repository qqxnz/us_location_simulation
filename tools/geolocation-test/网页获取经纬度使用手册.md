# 网页获取经纬度使用手册

## 1. 功能说明

网页可以通过浏览器提供的 Geolocation API 获取用户设备的当前位置，主要数据包括：

- 纬度：`latitude`
- 经度：`longitude`

获取位置前，浏览器会向用户申请定位权限。用户允许后，网页才能读取经纬度。

## 2. 使用条件

使用网页定位需要满足以下条件：

1. 设备已开启系统定位服务。
2. 浏览器拥有设备定位权限。
3. 用户允许当前网站访问位置。
4. 网页通过 HTTPS 访问。

本地开发时，可以通过 `http://localhost` 访问。普通 HTTP 网站通常无法使用定位功能。

## 3. HTML 页面

创建一个 `index.html` 文件：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>获取经纬度</title>
</head>
<body>
  <p>纬度：<span id="latitude">—</span></p>
  <p>经度：<span id="longitude">—</span></p>
  <button id="locate" type="button">获取当前位置</button>
  <p id="message"></p>

  <script>
    const latitude = document.querySelector('#latitude');
    const longitude = document.querySelector('#longitude');
    const message = document.querySelector('#message');
    const button = document.querySelector('#locate');

    button.addEventListener('click', () => {
      if (!navigator.geolocation) {
        message.textContent = '当前浏览器不支持定位。';
        return;
      }

      message.textContent = '正在获取位置…';

      navigator.geolocation.getCurrentPosition(
        position => {
          latitude.textContent = position.coords.latitude.toFixed(6);
          longitude.textContent = position.coords.longitude.toFixed(6);
          message.textContent = '获取成功';
        },
        error => {
          const errorMessages = {
            1: '定位权限被拒绝。',
            2: '当前无法获取位置。',
            3: '获取位置超时。'
          };

          message.textContent = errorMessages[error.code] || '获取位置失败。';
        },
        {
          enableHighAccuracy: true,
          timeout: 15000,
          maximumAge: 0
        }
      );
    });
  </script>
</body>
</html>
```

## 4. API 参数说明

`navigator.geolocation.getCurrentPosition()` 接收三个参数：

```javascript
navigator.geolocation.getCurrentPosition(
  successCallback,
  errorCallback,
  options
);
```

### successCallback

定位成功后执行。经纬度位于：

```javascript
position.coords.latitude
position.coords.longitude
```

### errorCallback

定位失败后执行。常见错误码如下：

| 错误码 | 含义 |
| --- | --- |
| `1` | 用户拒绝了定位权限 |
| `2` | 当前无法获取位置 |
| `3` | 获取位置超时 |

### options

| 参数 | 说明 |
| --- | --- |
| `enableHighAccuracy` | 是否请求高精度位置 |
| `timeout` | 最长等待时间，单位为毫秒 |
| `maximumAge` | 允许使用的位置缓存时长，`0` 表示请求最新位置 |

## 5. 本地运行

不要直接双击 HTML 文件。建议启动本地 Web 服务：

```bash
cd tools/geolocation-test
python3 -m http.server 8080
```

然后使用浏览器打开：

```text
http://localhost:8080
```

点击“获取当前位置”，并在浏览器弹出权限提示时选择“允许”。

## 6. 部署要求

部署到服务器时必须配置 HTTPS。例如：

```text
https://example.com/location/
```

通过普通 HTTP 地址访问时，浏览器可能直接禁止网页调用定位 API。

## 7. 常见问题

### 提示定位权限被拒绝

在浏览器的网站权限设置中允许当前网站使用位置信息，然后刷新页面重试。

### 一直显示正在获取位置

确认系统定位服务已开启，并在网络或卫星信号较好的环境中重试。

### 提示当前浏览器不支持定位

升级浏览器或更换支持 Geolocation API 的现代浏览器。

### 获取到的位置精度不高

网页无法指定设备必须使用某一种定位来源。实际精度由设备、系统、浏览器、网络环境和定位信号共同决定。

## 8. 隐私建议

经纬度属于敏感个人信息。使用时应当：

- 在获取位置前明确告知用户用途。
- 仅在用户主动操作后申请定位权限。
- 不在非必要情况下保存或上传经纬度。
- 如需将位置发送到服务器，应使用 HTTPS 并做好访问控制。
